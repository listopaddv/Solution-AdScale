# AdScale: задание 1. Архитектурная диагностика и целевое видение


Сейчас система обрабатывает до 15 000 запросов/с, но P95 времени ответа составляет 110-120 мс при требовании не более 100 мс. Общая база данных обслуживает аукцион, события, финансы и аналитику.

Предлагается постепенно выделять сервисы из монолита. Сначала отделить обработку ставок и приём событий, затем управление кампаниями, финансы и аналитику. Это позволяет подключить партнёра за три месяца и продолжить развитие без полной остановки системы.

## Цели

| Срок | Результат |
|---|---|
| Через 3 месяца | Не менее 18 000 запросов/с, общий P95 не более 100 мс, ответ новому DSP-партнёру не более 80 мс; раздельная обработка ставок и остальных операций |
| Через год | 50 000 запросов/с, доступность 99,9%, микросервисы, обмен событиями, несколько регионов и интеграция с несколькими площадками |

Требование партнёра в 80 мс не заменяется общим P95 в 100 мс. Способ измерения и учёт сетевой задержки нужно согласовать до подключения.

## Просмотр диаграмм

Откройте файлы `.puml` в расширении PlantUML для VS Code. Две основные диаграммы используют C4 из стандартной библиотеки PlantUML: `!include <C4/C4_Container>`. Загрузка библиотеки с GitHub не требуется. Для локального просмотра нужны Java, PlantUML и Graphviz.

Для локального просмотра настройте путь к установленному Graphviz. Если Graphviz недоступен, можно добавить `!pragma layout smetana` сразу после `@startuml`, чтобы использовать встроенный движок компоновки. Оба способа сохраняют нотацию C4.

Готовые изображения: [текущая архитектура](diagrams/AS-IS.svg), [целевая архитектура](diagrams/TO-BE.svg), [потоки ставок и событий](diagrams/RTB-and-Events.svg). После изменения исходников изображения нужно экспортировать заново.

В C4 контейнер означает приложение или хранилище данных, а не обязательно Docker-контейнер. Схема текущей системы сохраняет детализацию модулей из задания. Внутренние модули монолита не являются независимо развёртываемыми сервисами.

Документы описывают проектное решение. Производительность и доступность предстоит подтвердить испытаниями. Подробные протоколы RTB, схемы данных и расчёт инфраструктуры относятся к заданиям 2 и 3.

Справка по оформлению: [C4 Container](https://c4model.com/diagrams/container), [стандартная библиотека PlantUML](https://plantuml.com/stdlib), [Smetana](https://plantuml.com/smetana02).
